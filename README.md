# Mevaro Transport

Cinematic marketing site for Mevaro Transport (Vienna) — Lenis smooth scroll, GSAP ScrollTrigger object-motion chapters, and a WhatsApp intake dock that prefills the first chat message.

## Stack

- Next.js (App Router) + Tailwind CSS v4
- GSAP + `@gsap/react` + Lenis
- Agent craft skill: `.cursor/skills/insane-landing-motion`

## Develop

```bash
npm install
npm run dev
```
