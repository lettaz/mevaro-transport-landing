# Mevaro Transport — Cinematic Landing Design

## Through-line

As you scroll, cargo objects fly through Vienna nights into a clear booking path — proving Mevaro moves anything, fast and fair.

## Visual system

- **Mood:** Freight cinema — wet asphalt, sodium amber, signal crimson, cold white type
- **Not:** purple glow kitsch, cream terracotta, broadsheet
- **Type:** Syne (display) + DM Sans (body)
- **Tokens:** `--ink`, `--asphalt`, `--signal`, `--sodium`, `--fog`, `--paper`

## Acts

1. **Arrival** — Full-bleed night truck hero, brand as hero signal, kinetic headline, dual CTAs
2. **Cargo orbit** — Pinned stage; boxes / sofa / machine silhouettes scrub across while services copy stays readable
3. **Services track** — Horizontal scrub of five offers
4. **Proof** — Stats + reliability strip with count-up
5. **Book** — How-it-works + WhatsApp intake float (form → `wa.me` prefilled message)
